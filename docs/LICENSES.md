## Pretrained weights
The classifier is fine-tuned from the `efficientnet_b0` (ra_in1k) ImageNet weights distributed by the timm library (Apache 2.0); an earlier `mobilenetv3_large_100` run is kept in `model/eval/v1_eval.json` for comparison. PyTorch (BSD), torchvision (BSD), timm (Apache 2.0) and coremltools (BSD-3) are used only in the training pipeline, not in the app.

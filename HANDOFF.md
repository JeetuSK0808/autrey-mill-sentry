## 14 Oct, 01:25: two real bugs caught by the new real-model unit tests
- The two-output Core ML model's arrays were being read as zeros (deprecated data-pointer reads on IOSurface-backed arrays), then as a crash (`MLShapedArray<Float>` on float16 outputs). Fixed: outputs are read with the matching `MLShapedArray` scalar type, and the export now emits float32 outputs. `CoreMLClassifierTests` (4 tests: model loads with labels and centroids; privet reference photo -> privet with an embedding inside its class radius; ivy photo -> invasive through the real thresholds and gate; a cartoon leaf is never confirmed) pass on the simulator (CPU-only Core ML there; the simulator's GPU backend rejects the model). The phone has the fixed build (installed 01:20).
